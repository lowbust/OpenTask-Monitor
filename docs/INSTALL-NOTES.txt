OpenTask Monitor — ранняя версия 0.2.x

Python и дополнительные компоненты вручную устанавливать не нужно.
Приложение устанавливается только для текущего пользователя.

Это не антивирус. Завершение процессов может потерять несохранённые данные,
остановка служб может нарушить работу Windows.

ВАЖНО: отключённые записи автозагрузки НЕ восстанавливаются при удалении программы.
Сначала включите их в приложении или сохраните резервный JSON:
%LOCALAPPDATA%\OpenTaskMonitor\startup-backup.json

Установщик не удаляет эту папку данных.
