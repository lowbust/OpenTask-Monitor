OpenTask Monitor 0.2.2 — Windows 10/11 x64

В публичном portable ZIP только один OpenTaskMonitor.exe.
Распакуйте его в обычную папку и запустите. Python/команды/установщик не нужны.
Папку runtime рядом носить больше не нужно.

При первом запуске встроенные компоненты автоматически распакуются без интернета
в %LOCALAPPDATA%\OpenTaskMonitor\packages\<версия-хеш>. Появится окно подготовки;
нужны несколько сотен МБ диска. Следующие запуски используют кеш.
Это один файл для распространения, но НЕ исполнение без файлов на диске.

ОБА РЕЖИМА
Запуск → Случайное имя при следующем запуске → закройте → снова откройте тот же EXE.
Для обычного режима снимите флажок и повторите. Это не self-defense и не обход AV.

ФУНКЦИИ
Выберите процесс → Анализ…: подпись, VT, дерево, DLL, сеть, File/Key handles.
Инструменты: фоновые подписи offline, завершение дерева, удаление EXE/reboot delete.
VirusTotal только вручную: свой API-ключ в RAM, передаётся SHA-256, не сам файл.
Подпись/путь/родитель/VT не являются диагнозом вируса или гарантией безопасности.
Suspend не делает изучение вируса безопасным. Kernel драйвера нет.

ЛИЦЕНЗИИ И КЕШ
Справка → Лицензии и сведения о сборке… открывает legal notices и BUILD-INFO.json.
Копии DLL в кеше динамические, допускается замена ABI-совместимыми версиями.
После закрытия всех версий можно удалить только packages, чтобы очистить кеш.
Следующий запуск распакует его снова. Старые кеши автоматически не удаляются.
Не удаляйте startup-backup.json: там отключённая Run/RunOnce, её удаление не восстановит.

Исходники находятся в отдельном source ZIP для GitHub. EXE размещайте в Releases.
Сборка без цифровой подписи; не отключайте SmartScreen/антивирус. Версия alpha.
Результаты и границы фактических тестов: VERIFICATION.md в кеше/исходниках.
