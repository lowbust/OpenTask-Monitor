# Для пользователя 0.3.0

В portable ZIP находится **только OpenTaskMonitor.exe**. Распакуйте и запустите.
Никаких исходников, pip, Python или папки runtime рядом не требуется.
При первом запуске появится подготовка: встроенные библиотеки распакуются offline
в `%LOCALAPPDATA%\OpenTaskMonitor\packages\<сборка>`. Нужны свободное место и права
на папку данных. Повторный запуск использует кеш. Это не installer, но файлы в
профиле пользователя всё же создаются; на другой ПК переносится только EXE.

В меню **Запуск** — переключение обычного/случайного режима для следующего запуска.
Закройте и снова откройте тот же EXE; отдельного Random.exe нет. Это не защита
процесса от malware/завершения. Kernel driver отсутствует.

Выберите процесс → **Анализ…**: подпись, VirusTotal, дерево, DLL, сеть, дескрипторы.
В **Инструментах** — подписи списка по флажку и опасные действия. Столбец «Проверка»
справа, прокручивается горизонтально. Ctrl+F — поиск, Ctrl+S — CSV.

CPU/RSS обновляются по интервалу, metadata кешируется до 15 s, autosort — раз в 5 s.
Фоновые подписи выключены по умолчанию. VT — свой ключ в RAM, hash-only, по согласию.
Не передавайте разработчику API-ключ. Неподписанный EXE не обязательно вирус,
валидная подпись/0 detections не доказывают безопасность. Handles — частичный снимок.
Сеть: разрыв только IPv4 TCP с нужными правами, переподключение не блокируется.
Run/RunOnce backup/restore; задания/Startup folders — read-only. Это не полный Autoruns.

Операции завершения/удаления необратимы и могут нарушить работу системы; Suspend
не гарантирует безопасность. Для изучения malware используйте изолированную VM.
Для администратора закройте программу и запустите EXE правой кнопкой → от администратора.

**Справка → Лицензии и сведения о сборке…** открывает legal notices в кеше.
Можно заменить LGPL-библиотеки ABI-совместимыми версиями после закрытия приложения.
Ненужные старые кеши packages можно удалить, когда все версии закрыты. Не удаляйте
startup-backup.json с отключёнными Run/RunOnce; удаление EXE их не включает.
Логи: `%LOCALAPPDATA%\OpenTaskMonitor`. Собственный EXE не подписан; не отключайте AV.
Проверено под Wine, не полноценной Windows VM; см. VERIFICATION.md.


## Новые проверки 0.3.0

1. Выберите процесс → Анализ… → **Память / потоки**. Запустите read-only проверку;
   предел 15 с. В отчёте — количество сравниваемых/различающихся байтов, регионы,
   адреса потоков и ограничения. Отличия кода/потоки вне модулей бывают у обычных
   JIT/hooks/AV; не завершайте процесс только на этом основании.
2. **Права токена** → прочитать. Включённые чувствительные права выделены.
   Elevation/integrity показываются отдельно; это не доказательство злоупотребления.
3. Столбец **Приоритет 0–100** — справа, hover показывает слагаемые. Красный ≥60.
   Закрепление сверху отключается в Инструментах. Это не «процент заражения».
   Приоритет/причины также включены в CSV. Фоновые подписи включайте отдельно,
   неизвестная подпись не считается отсутствующей.
4. **Инструменты → Снимки / hosts / DNS / IFEO / аудит / GPU…**:
   - Сохраните JSON-эталон или загрузите ранее снятый. Сравнение показывает новые,
     удалённые и изменённые элементы; задания включаются отдельным флажком.
     Фильтр новых EXE сравнивает путь/имя/пользователя, не PID/содержимое EXE.
   - На вкладке hosts/DNS/IFEO прочитайте состояние, затем при необходимости включите
     наблюдение. Изменения не блокируются; записи IFEO автоматически не удаляются.
   - На вкладке audit выберите существующий Sysmon/Security канал. Если журнал
     отсутствует/закрыт, это не означает отсутствие опасных действий. Sysmon здесь
     не устанавливается; ключи/clipboard/все WinAPI не перехватываются.
   - GPU: вручную или optional обновление 5 с, только на этой вкладке. NVML NVIDIA,
     история 60 измерений первой карты, остальные — текстовый снимок. н/д — нет
     доступного сенсора, не ноль. Тепловая инерция не доказывает наличие майнера.
5. Карантин: выберите процесс → Инструменты/контекстное меню → **Карантин**.
   После подтверждения создаётся и проверяется ZIP-контейнер .vir; затем процесс
   завершается и EXE удаляется без корзины. При отказе доступа исходник может
   остаться, контейнер сохранится. Это не sandbox и не защита от извлечения.
   Просмотр списка/папки — в системных инструментах. Авто-восстановления/запуска нет.

Мониторы выключены при открытии окна; закрытие системного окна прекращает наблюдение.
Нет kernel anti-kill/Protected Process, случайного hash или надёжного keylogger-детектора.
Случайное имя не делает программу неуязвимой. Подробно: SECURITY-ANALYSIS.md.
