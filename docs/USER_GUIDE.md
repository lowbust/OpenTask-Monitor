# Для пользователя 0.2.2

В portable ZIP находится **только OpenTaskMonitor.exe**. Распакуйте и запустите.
Никаких исходников, pip, Python или папки runtime рядом не требуется.
При первом запуске появится подготовка: встроенные библиотеки распакуются offline
в `%LOCALAPPDATA%\OpenTaskMonitor\packages\<сборка>`. Нужны свободное место и права
на папку данных. Повторный запуск использует кеш. Это не installer, но файлы в
профиле пользователя всё же создаются; на другой ПК переносится только EXE.

В меню **Запуск** — переключение обычного/случайного режима для следующего запуска.
Закройте и снова откройте тот же EXE; отдельного Random.exe нет. Это не защита
процесса от malware/завершения. Kernel driver отсутствует.

Выберите процесс → **Анализ…**: подпись, VirusTotal, дерево, DLL, сеть, дескрипторы.
В **Инструментах** — подписи списка по флажку и опасные действия. Столбец «Проверка»
справа, прокручивается горизонтально. Ctrl+F — поиск, Ctrl+S — CSV.

CPU/RSS обновляются по интервалу, metadata кешируется до 15 s, autosort — раз в 5 s.
Фоновые подписи выключены по умолчанию. VT — свой ключ в RAM, hash-only, по согласию.
Не передавайте разработчику API-ключ. Неподписанный EXE не обязательно вирус,
валидная подпись/0 detections не доказывают безопасность. Handles — частичный снимок.
Сеть: разрыв только IPv4 TCP с нужными правами, переподключение не блокируется.
Run/RunOnce backup/restore; задания/Startup folders — read-only. Это не полный Autoruns.

Операции завершения/удаления необратимы и могут нарушить работу системы; Suspend
не гарантирует безопасность. Для изучения malware используйте изолированную VM.
Для администратора закройте программу и запустите EXE правой кнопкой → от администратора.

**Справка → Лицензии и сведения о сборке…** открывает legal notices в кеше.
Можно заменить LGPL-библиотеки ABI-совместимыми версиями после закрытия приложения.
Ненужные старые кеши packages можно удалить, когда все версии закрыты. Не удаляйте
startup-backup.json с отключёнными Run/RunOnce; удаление EXE их не включает.
Логи: `%LOCALAPPDATA%\OpenTaskMonitor`. Собственный EXE не подписан; не отключайте AV.
Проверено под Wine, не полноценной Windows VM; см. VERIFICATION.md.
