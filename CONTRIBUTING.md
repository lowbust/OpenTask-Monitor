# Участие в разработке

1. Создайте fork и отдельную ветку.
2. Установите Python 3.11+ и `python -m pip install -e ".[dev]"` в venv.
3. Запустите `python -m ruff check .` и `python -m pytest -q`.
4. Системные действия проверяйте в Windows VM со снимком, не на рабочей машине.
5. В PR опишите изменение, проверенную Windows/Python и способ воспроизведения.

Правила: никаких shell-команд из пользовательского ввода, скрытой телеметрии,
автоматического повышения прав, загрузки кода из сети или действий над процессом
только по PID без проверки времени создания. Не добавляйте «процент опасности»
без проверяемой модели: системный диспетчер не должен выдавать догадки за диагноз.
Фоновые операции не должны блокировать GUI. Все опасные изменения — с явным
подтверждением и обработкой отказа доступа. Новая логика должна иметь тесты.

Отправляя изменения, вы соглашаетесь распространять их под MIT; права на
сторонние зависимости остаются за их авторами.
